


Simple application to demonstrate the use of JSON Web Tokens.

The features are:

* High users.
* Authentication of users according to the password Generation JSON Web Tokens.
* Simple application to show the records of a mysql table (clients) allowing to record modify and delete records associated to the user that is logged in.


Instalacion: 

index.php 						linea 9 	modificar la constate URL con el valor del servidor. 
\app\models\mysql_clientes.php 	linea 14 	modifica los datos de acceso al servidor mysql	
\app\models\mysql_users.php 	linea 14 	modifica los datos de acceso al servidor mysql
